A · 결정 말풍선 추천 · 적용

Grain — 깎인 MSG 결정 한 알이 그대로 말풍선이 된다

정육각형 결정(빛 받는 윗면 · 그늘진 옆면 둘)의 왼쪽 아래 모서리가 말풍선 꼬리로 빠져나온다. 한 덩어리 실루엣이라 16px 에서도 형태가 무너지지 않는다.

  • 단색: 실루엣 + Y자 홈
  • 스피너: 꼬리를 뗀 결정이 천천히 회전
  • 세 면 = 세 단계 인디고, 테마마다 틴트만 교체

B · 한 꼬집

Pinch — 말풍선 어깨에 결정 한 알을 톡

평범한 말풍선(=AI 대화) 위에 결정 알갱이가 살짝 얹힌다. "조연" 이야기를 가장 직접적으로 말하지만, 16px 에서는 알갱이가 점으로 뭉개진다.

  • 단색: 알갱이 둘레를 배경색으로 끊어야 함
  • 두 요소라 파비콘에서 약함

C · 감칠 점

Typing grains — 입력 중 점 세 개가 결정 알갱이

"상대가 입력 중…" 점 세 개를 마름모 결정으로 바꿨다. 채팅 앱이라는 건 바로 읽히지만 흔한 말풍선 실루엣이라 다른 메신저와 구별이 약하다.

  • 단색: 알갱이를 뚫어서 표현
  • 16px 에서 점 간격이 1px 수준
