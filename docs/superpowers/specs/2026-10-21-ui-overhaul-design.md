### 3.5 사용량 헤더 → 요약 칩 + 시트

칩 한 개, 현재 세션의 계정만. 형태와 상태 규칙(`UsagePanel.tsx` 의 `levelClass`·`stale`·`estimated` 로직을 그대로 쓴다):

|---|---|---|---|
| 정상 | `A 42% · 2h` (가장 가까운 리셋) | `A 42%` | `--muted` 글자, 점 없음 |
| 다음 턴 다른 계정 (route_preview, **폰도 켠다**: `next={preview}`) | `A→B 42% · 2h` | `A→B` | 화살표 `--accent`; title/aria 에 이유(`next.reason`)·Opus 여부 |

| 위험 ≥95% / 소진 | `A 97% · 12m` / `A 소진 · 12m` | `A 97%` / `A ✕` | `--danger` 글자, 배경 danger 10% |
| 추정(estimated, cli 모드) | 숫자 점선 밑줄 (현행 규칙) | 같음 | — |
| 오래됨(usage-deck 안 닿음 / `trustUntil` 지남) | `A 42% · 오래됨` | `A 42%` + 속 빈 점 | `--faint`, 숫자 흐림 .65 |

| 다른 계정이 위험 | 칩 끝 작은 `--danger` 점 하나 | 같음 | — |
| **숫자 전혀 없음**(현재 계정 없고 모든 자리 값 없음) | **칩 숨김** | 숨김 | — |

- 숫자 변경: 숫자만 150ms 크로스페이드. `font-variant-numeric: tabular-nums`.
- aria-label 예: "A 계정 사용량 42퍼센트, 2시간 뒤 초기화, 다음 턴은 B 계정". 승인 대기 배지가 있으면 폰에서 칩이 `A42` 로 먼저 줄어든다(활동 점 양보).

### 3.7 분할 보기

- 데스크탑 pane 머리 = 세션 칩 하나(제목 + ▾) + 조건부 칩(갈라짐·사령탑·⚠). ✕ 는 칩 메뉴 "창 › 이 창 닫기"(⌘⇧X 유지), 그립은 칩 자체 드래그(`pane-grip` 의 pointer/keyboard 핸들러를 칩에 붙임).
- 빈 pane: 가운데 "세션을 끌어오거나 선택" 텍스트 + 목록, 머리 버튼 0.
- 상단 "+ 분할" 은 아이콘 1개, 5개면 비활성.
- **폰 분할**: pane ≥2 일 때만 상단바 아래 36px 탭 스트립 유지(탭 높이 44 터치, 라벨 "1 · deck UI…", 스와이프 재정렬 `tabs.stripProps` 유지, 끝에 "+"). 1개면 스트립 없음. 세션 칩 메뉴 "창 › 다른 분할로…" 가 중복 입구.
- 떠 있는 카드(데스크탑): 카드 머리 = 세션 칩 + 접기(–/▭) + 닫기(✕) 2 아이콘만. 최대화는 머리 더블클릭(현행) + 메뉴. 크기 조절 핸들 유지.

### 3.9 활동 점 — 폰에서 유일한 출구

폰에서는 작업 현황·하이라이트·서버 칩이 없으므로 활동 점이 **다른 세션의 승인 요청을 보여주는 유일한 상단 입구**다. 그래서 점이 아니라 "배지가 붙는 버튼"이다.

집계(앱 상태에서 바로 계산, 새 서버 메시지 없음):
- `waiting` = `state.pending` + `state.questions`(세션 불문, orphan 포함) + `tasks[].waiting` — **승인·질문 대기**
- `running` = `state.activity.filter(a.running)`, `bg` = `a.bg > 0`
- `server` = 업데이트 대기(파일 N) · 재시작 대기(draining) · 재시작됨 1회
- `conn` = `!state.connected`, `build` = `newBuild`, `notifyBlocked` = NotifyMenu blocker

표시 규칙(우선순위 위에서 아래, 하나만):

| 상태 | 점 | 배지 | 모션 |
|---|---|---|---|
| 연결 끊김 | `--danger` 점 | — | 없음(배너가 말함) |
| **승인 대기 ≥1** | `--warn` 점 | **숫자 = 승인 대기 수**, `--warn` 배경·`--bg` 글자, 점 오른쪽 위 | 펄스 1.2s(reduced-motion 시 정적, 점 테두리 2px) |
| 재시작/업데이트 대기 | `--muted` 점 | ↻ 오버레이 | 없음 |
| 실행 중 ≥1 | `--accent` 점 | — | 없음(실행 중은 흔하다) |
| 백그라운드만 | `--muted` 점 + 작은 안쪽 점 | — | — |
| 아무것도 없음 | `--faint` 속 빈 점 | — | — |

- 터치 타깃 44×44(아이콘 20 + 패딩 12). aria-label 예: "활동 · 승인 대기 2 · 실행 중 1". 승인 대기가 생기면 `aria-live="polite"` 한 줄(기존 `cards-live` 재사용).
- 다른 세션에서 승인이 오면 **토스트 1회**("deck UI 다듬기 · 승인 대기 — 열기", 8초, 폰·데스크탑 공통). 토스트가 사라져도 배지 숫자는 남는다.
- 시트(폰 바텀시트 / 데스크탑 오른쪽 320px): ① **승인 대기** — `PermissionCard`/`QuestionCard` 그대로 끼워 **시트 안에서 바로 승인/답변**(세션 전환 없이) ② 실행 중(세션 행, 눌러 열기, 중단) ③ 백그라운드 작업(작업별 정지) ④ 하이라이트(기존 Highlights 탭) ⑤ 서버(가동 시각 · 업데이트/재시작 · 지금 재시작) ⑥ 알림 설정 링크(+ blocker 경고). 비어 있으면 "지금 실행 중인 작업이 없어요 · 새 대화".
- Esc 로 닫힘(`hasOpenPopup` 소유자 목록에 추가), `role="dialog"` + 포커스 트랩.

## 8. 사용자 결정 — 2026-10-21 확정: 세 가지 모두 권장안대로

1. **사이드바 "프로젝트 보기"를 없애고 그룹 헤더로 흡수해도 되나?** (최근/프로젝트 토글 제거) — 권장: 없앤다. 대신 검색창에서 프로젝트명 필터, 행 아바타 색으로 프로젝트 구분. **없앨 때 지켜야 할 것(검토 반영)**: 프로젝트별 "+ 새 세션"은 사이드바 "+" 메뉴의 프로젝트 목록으로, "보관됨"은 목록 맨 아래 한 행으로, "폴더 열기"(FolderPicker)는 "+" 메뉴 "다른 폴더에서…"로 남긴다(§3.8 #26). 프로젝트별 묶음이 꼭 필요하면 "+" 메뉴 옆 정렬 옵션 하나(시간순/프로젝트순)로 남긴다.
2. **사용량 요약 칩에 "현재 계정만" 보일지, "A42 B10 C89" 세 글자씩 다 보일지?** — 권장: 현재 계정 + 다음 턴 전환 예고(`A→B`, **폰에서도**) + 다른 계정이 위험이면 작은 빨간 점 하나. 경고·위험·오래된 값 상태는 §3.5 표대로 칩에 남는다. 세 계정 다 보이면 폰에서 다시 두 줄이 된다. 전체는 시트에서.
3. **메시지 액션을 폰에서 "길게 누르기"로 숨겨도 되나?** — 권장: 숨긴다. 단 **`(hover:none)` 에서 마지막 답장의 액션은 상시 유지**(복사·재시도 1탭), 그 외 메시지는 길게 누르기 메뉴에 **편집·재시도·다시 생성·다른 모델로·버전 ‹›** 까지 전부 넣는다(기능 손실 0). 데스크톱은 현행 hover 그대로.
