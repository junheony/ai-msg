## 1. 로컬 앱

로컬 앱은 이용자의 컴퓨터에서 실행됩니다. 데이터는 이용자 기기에만 저장되고, 저희는 받지 않습니다.

**앱이 읽는 파일.** 세션과 사용량을 보여 주려고 아래 파일을 읽습니다.

| 읽는 것 | 이유 |
|---|---|
| 벤더 도구가 남긴 대화 기록(예: Claude 프로필 폴더, Codex 세션 폴더) | 세션 목록과 기록을 보여 주려고 |
| 이용자가 작업하려고 고른 폴더 | 그 폴더에서 벤더 도구를 실행하고 파일을 미리 보여 주려고 |
| 벤더 도구가 턴마다 출력하는 사용량 수치 | 남은 한도를 보여 주려고 |

앱은 벤더 로그인 토큰, 키 파일, 키체인을 읽지 않습니다. Gemini 는 자격증명 파일이 있는지만 확인하고 열지 않습니다.

**앱이 쓰는 파일.** 앱 자체 설정, 세션 상태, 권한 결정 감사 기록, 하이라이트(7일 보관), 업로드한 첨부(7일 뒤 삭제), 푸시 키, 사용량 집계를 이용자 기기의 앱 설정 폴더에만 씁니다.

**실험적 기능(기본 꺼짐).** 데스크톱 AI 앱의 세션 파일이나 다른 도구의 로컬 기록처럼 다른 앱의 로컬 파일을 읽는 기능이 있습니다. 설정에서 기능마다 직접 켜야 합니다. 꺼져 있으면 그 파일을 읽지 않습니다. 다른 앱의 데이터베이스는 임시 복사본으로만 열고, 세션 미러링 설정이 켜진 경우를 빼고는 그 폴더에 쓰지 않습니다 `{{확인 필요: 실험 기능별 읽기·쓰기 범위 최종 목록(제품 확정 후)}}`.

**로컬 푸시.** Pro 클라우드 없이 푸시를 쓰면 이용자 기기가 알림을 직접 보내고, 구독 정보는 기기의 자기 폴더에 보관합니다.

## 2. Pro 클라우드

Pro 클라우드는 이용자가 로그인하고 기기를 연결한 경우에만 존재합니다.

**저희가 가지고 있는 데이터**

| 데이터 | 목적 |
|---|---|
| 계정 이메일, 생성 시각 | 이메일 링크 로그인, 결제 대조, 이메일당 1회 체험 제한 |
| 로그인 링크·웹 세션 기록(해시로 저장) | 인증 |
| 컴퓨터 이름, 공개키, 연결 시각 | 기기 등록 |
| 페어링한 폰·브라우저 이름, 공개키, 상태, 마지막 접속 시각 | 페어링과 릴레이 접근 |
| 페어링 시도 기록 | 안전한 페어링 |
| 체험 시작·종료 시각 | 체험 |
| 구독 상태, 요금제, 결제 기간, 해지 상태, Paddle 고객·구독 ID, 환불 상태 | 이용권(쓸 수 있는 Pro 기능) 확인 |
| Paddle 웹훅 이벤트 기록 | 결제 동기화와 중복 처리 방지 |
| 이용자가 등록한 푸시 endpoint 의 해시 | 푸시 요청이 이용자 본인 것인지 확인 |
| 속도 제한 카운터(이메일·IP 주소 기준) | 남용 방지 |
| 운영 로그: 이벤트 종류, 기기 ID, 바이트 수. 메시지 내용은 없음 | 서비스 운영과 보안 `{{확인 필요: 로그에 IP 주소가 남는지, 보관 기간}}` |
| 이용자에게 보낸 메일(로그인 링크) | 전달 `{{확인 필요: 메일 발송 업체와 발송 기록 보관}}` |

**저희가 볼 수 없는 것.** 세션 내용, 프롬프트, 코드, AI 결과물은 암호화된 데이터로 릴레이를 지나갑니다. 키는 이용자의 페어링한 기기에만 있습니다. 저희는 풀 수 없고, 저장하지도 않습니다.

**푸시 알림.** 푸시를 보낼 때 이용자의 컴퓨터가 알림을 암호화하고, 클라우드는 서명해서 이용자 브라우저의 푸시 서비스(예: 브라우저 업체가 운영하는 서비스)로 전달만 합니다. 클라우드 푸시 문구에는 세션 제목과 이벤트 종류만 들어 있고, 코드나 명령은 들어 있지 않습니다. 저희는 push endpoint 자체가 아니라 그 해시를 보관합니다 `{{확인 필요: 푸시 구독 전문을 클라우드가 저장하는지}}`.

**서비스 제공업체.** Pro 클라우드를 운영하려고 인프라·메일 업체를 씁니다 `{{확인 필요: 호스팅·메일 업체 이름과 서버 지역}}`. 브라우저의 푸시 서비스는 이용자 기기로 푸시가 갔다는 사실을 알게 됩니다.

**보관 기간.** 계정이 있는 동안 계정 데이터를 보관합니다. 로그인 링크나 페어링 시도 같은 단기 기록은 시간이 지나면 만료됩니다 `{{확인 필요: 만료 기간과 정리 주기}}`. 계정을 삭제하면 `{{확인 필요: 삭제 기한}}` 안에 데이터를 지웁니다. 결제 기록처럼 법이 보관을 요구하는 것은 예외입니다 `{{확인 필요: 법정 보관 기간}}`.

**권리와 삭제 요청.** `{{CONTACT_EMAIL}}` 로 연락하면 데이터의 열람·정정·내보내기·삭제와 계정 해지를 요청할 수 있습니다. 앱에서는 언제든 컴퓨터나 폰의 연결을 해제할 수 있습니다. `{{확인 필요: 적용 법령(GDPR·CCPA·한국 개인정보 보호법 등)별 권리·고지 문구}}`
